# Part-1-Project-Team-10
---
A productivity and management system

When you clone the repo run ``` uv sync ``` to get all the packages needed. </br>
If using VSCode use the launch.json in the .vscode folder to run the program </br>

src - all code for adding functionality </br>
gui - all guis </br>
services - any actions, permission checks or services live e.g. login verification </br>
users/models - all code for user data e.g. user classes
